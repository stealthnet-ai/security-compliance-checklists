# StealthNet AI Security Compliance Checklists

Practical penetration-testing preparation checklists for teams navigating common security assurance and regulated-industry requirements.

These resources help security leaders, engineering teams, vCISOs, MSPs, and compliance advisers prepare an authorized assessment with clear scope, useful evidence, and an actionable remediation path.

## How to use these resources

1. Select the checklist aligned to your immediate assurance or regulatory objective.
2. Use it before scoping the assessment to identify systems, owners, test accounts, evidence needs, and reporting priorities.
3. Keep the checklist with your authorization, scope, findings, remediation, and retest records.
4. Confirm current requirements with the applicable auditor, assessor, regulator, contract, and authoritative framework source.

## What a useful penetration test produces

- An explicitly authorized scope and rules of engagement
- Technical findings with clear evidence and impact
- Prioritized remediation guidance
- Evidence appropriate to the organization’s assurance objective
- Retest or validation results where remediation is completed
